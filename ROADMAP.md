# Roadmap / 路线图

This roadmap communicates direction, not a delivery guarantee. Priorities may change based on verified user feedback and maintainer capacity.

路线图用于说明方向，不构成交付承诺；优先级会根据可验证的用户反馈与维护能力调整。

## Now — stabilize the foundation / 当前：稳定基础

- Expand unit and API coverage for imports, diagnosis validation, and authorization.
- Document self-hosting and ChatGPT Sites deployment with synthetic examples.
- Establish public issue triage, changelog, and release cadence.
- Improve accessibility and mobile regression checks.

- 补充导入、诊断校验和权限隔离的单元与 API 测试。
- 使用合成数据完善自部署和 ChatGPT Sites 发布文档。
- 建立公开 Issue 分类、更新日志和发布节奏。
- 加强无障碍与移动端回归检查。

## Next — make workflows reusable / 下一步：提升可复用性

- Configurable diagnosis and follow-up templates.
- Optional organization/team taxonomy and import mappings.
- Redacted audit events for critical workflow transitions.
- Additional export formats and report templates.

- 可配置的诊断与跟进模板。
- 可选的组织/团队分类与导入映射。
- 关键流程状态变化的脱敏审计事件。
- 更多导出格式和报告模板。

## Later — ecosystem integrations / 后续：生态集成

- Pluggable identity and database adapters for non-Sites deployments.
- Maintainer automation for issue triage, regression-test suggestions, documentation checks, and release notes—with human approval before every merge or release.

- 面向非 Sites 部署的可插拔身份与数据库适配器。
- Issue 分类、回归测试建议、文档检查和发布说明等维护自动化；所有合并和发布仍须人工确认。

Open a feature request to discuss a roadmap item before starting a large implementation.

开始大型实现前，请先创建功能建议 Issue 讨论范围。
