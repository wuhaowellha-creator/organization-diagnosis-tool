# HRBP / 组织诊断工具 MVP v0.1 Codex 开发总任务书

## 0. 总体开发原则

本项目当前处于开发前阶段。

MVP v0.1 已冻结，只开发一个单用户最小闭环：

工作记录 -> AI 诊断 -> 人工确认 -> 跟进事项 -> 报告文本

开发过程中不得扩展为复杂 SaaS，不得新增多租户，不得新增企业微信 / 飞书 / 钉钉集成，不得新增复杂数据看板，不得新增 HR 全模块。

## 1. 统一命名说明

为避免 Codex 自行扩展，统一命名如下：

| 业务说法 | 工程实现 |
| --- | --- |
| 诊断项目 | `work_records` 工作记录 |
| AI 诊断结果 | `ai_diagnoses` |
| 一事一档 / 跟进事项 | `follow_up_items` |
| 周报 / 诊断摘要 | `report_outputs` |

v0.1 不新增 `projects` 表，不新增员工表，不新增部门表，不新增组织表，不新增租户表。

## 2. 总体技术栈

| 层级 | 技术 |
| --- | --- |
| 框架 | Next.js App Router |
| 语言 | TypeScript |
| 样式 | Tailwind CSS |
| 数据库 | Supabase Postgres |
| 鉴权 | Supabase Auth |
| AI | OpenAI API Structured Outputs |
| 部署 | Vercel |

## 3. 任务总览

| 任务 | 名称 | 目标 |
| --- | --- | --- |
| Task 01 | 初始化项目 | 项目能启动 |
| Task 02 | 搭建基础页面和布局 | 页面骨架可访问 |
| Task 03 | 配置样式和基础组件 | UI 基础能力可复用 |
| Task 04 | 配置数据库连接 | Supabase 可连接 |
| Task 05 | 实现用户登录 | 单用户登录可用 |
| Task 06 | 实现工作记录创建 | 可新建一条诊断输入 |
| Task 07 | 实现工作记录列表和详情 | 可查看已创建记录 |
| Task 08 | 实现 AI 诊断表单结构 | 页面可展示和编辑诊断字段 |
| Task 09 | 实现诊断结果保存与确认 | 人工确认机制可用 |
| Task 10 | 实现 AI 诊断生成接口 | 可生成结构化诊断 |
| Task 11 | 实现跟进事项模块 | 中高风险可转为跟进事项 |
| Task 12 | 实现报告生成与最小历史记录 | 可生成和查看报告文本 |
| Task 13 | 全流程测试和修复 | 主流程跑通 |
| Task 14 | 补充 README 和部署说明 | 项目可交接、可部署 |
