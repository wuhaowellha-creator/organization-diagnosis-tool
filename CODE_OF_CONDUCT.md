# Code of Conduct / 社区行为准则

## Our commitment / 我们的承诺

We are committed to a respectful, inclusive, and harassment-free community. We value evidence-based discussion, empathy for users, and constructive review of ideas and code.

我们致力于建设尊重、包容、无骚扰的社区，鼓励基于事实的讨论、对用户的同理心，以及对观点和代码的建设性评审。

## Expected behavior / 期望行为

- Be respectful and specific when giving feedback. / 反馈应尊重他人并保持具体。
- Assume good intent while addressing harmful impact. / 在指出不良影响时，优先假设善意。
- Protect personal and HR-sensitive information. / 保护个人信息与 HR 敏感信息。
- Accept maintainer decisions on scope, safety, and release readiness. / 尊重维护者对范围、安全与发布准备度的决定。

Harassment, discrimination, threats, doxxing, and publication of sensitive organizational data are not tolerated. Report conduct concerns privately through the maintainer's GitHub profile. Maintainers may edit, hide, reject, or remove contributions and restrict participation when necessary.

社区不接受骚扰、歧视、威胁、人肉搜索或公开组织敏感数据。行为问题请通过维护者 GitHub 主页私下报告。必要时，维护者可编辑、隐藏、拒绝或删除贡献，并限制参与权限。
